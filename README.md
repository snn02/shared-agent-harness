# shared-agent-harness

Репозиторий для разработки общего agent harness. Версионный Windows-пакет собирается из `distribution/windows/`. Оригиналы источников и полный структурированный разбор хранятся отдельно от пакета.

## Текущий статус

- Версия исходников пакета — кандидат 0.4.2. Общий каталог `%USERPROFILE%\.agents` предназначен для правил, навыков, нейтральных выжимок и курируемой памяти. Установка в реальный профиль не подтверждена проверками этого репозитория.
- Навыки: `document-ingest` разбирает документ в выбранный каталог; `source-to-knowledge` помогает получить выжимку или идею; `memory-maintenance` обслуживает одобренные записи памяти.
- Личная библиотека источников — отдельный проект для оригиналов, полного текста и индекса. Она не входит в ZIP.
- Пакет распространяется как версионный ZIP; обновления принимаются вручную. Git remote и опубликованный выпуск пока не созданы.

## Установка

Когда выпуск будет опубликован, скачайте ZIP и файл SHA-256 со страницы GitHub Releases, проверьте контрольную сумму, полностью распакуйте ZIP и запустите `install.cmd`. Пошаговое описание доступно в [инструкции](distribution/windows/installation-guide.md). Сейчас 0.4.2 остаётся кандидатом, а не опубликованным выпуском.

Исходники проекта распространяются на условиях [MIT](LICENSE). Внешние зависимости устанавливаются отдельно и распространяются на условиях их собственных лицензий. Текущий кандидат ZIP 0.4.2 ещё не содержит файл лицензии; перед выпуском пакет необходимо дополнить уведомлением об условиях MIT.

## Разработка

Сборка в PowerShell: `./tools/build-windows-release.ps1 -OutputDirectory ./dist/release -ExpectedVersion 0.4.2`; выберите пустой каталог результата. Запускайте `install.cmd` только из полностью распакованного ZIP: `manifest.json` создаётся при сборке и отсутствует в исходной папке. Состав пакета задан в сборщике.

Проверки находятся в `tests/windows/` и `tests/ingest/`. Windows-тесты используют каталог `dist/test-scratch`, который нужно создать перед запуском. Для Python-тестов нужны Python 3.12, зависимости из `distribution/windows/payload/skills/document-ingest/scripts/requirements.txt` и дополнительная тестовая зависимость PyMuPDF. Чтобы запуск Python-тестов не оставлял `__pycache__` в исходниках пакета, задайте в PowerShell `$env:PYTHONDONTWRITEBYTECODE = '1'` и выполните `python -m unittest discover -s tests/ingest -v`. Сборщик отклоняет посторонние файлы в исходной папке пакета.

Версия пакета хранится в `distribution/windows/version.txt`; сборщик добавляет её в имя ZIP и манифест. Git-коммиты фиксируют изменения между отправками, а теги `vX.Y.Z` предназначены для проверенных выпусков. Порядок подготовки выпуска описан в `CHANGELOG.md`.
