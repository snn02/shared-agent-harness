# Разбор документа

Обрабатывай один явно указанный файл в один явно указанный каталог. Этот навык не выбирает личную библиотеку, не читает профиль или память и не делает предметную выжимку.

1. Уточни происхождение материала по словам пользователя и контексту задачи, если оно неясно. Для клиентского материала до передачи текста или изображений модели проверь разрешение владельца и правила клиента для выбранного провайдера; при неясности остановись. Храни результат в разрешённом проекте. Сам CLI не умеет распознавать клиентские данные и не выбирает каталог за пользователя.
2. Убедись, что Python 3.12 и закреплённые зависимости доступны. Если нет, по решению владельца запусти `scripts/setup-runtime.ps1`; установщик harness этого не делает. Скрипт выводит путь к Python в отдельном личном окружении. Для OCR отдельно проверь Tesseract и модели языков.
3. Запусти `<путь-к-Python-окружения> scripts/ingest.py --source <файл> --output <каталог-документа> --document-id <устойчивый-slug>`. При новой редакции в том же каталоге сначала сравни источник, затем добавь `--update`. Не обрабатывай весь каталог источников одним вызовом.
4. Открой `manifest.json` и `index.md`. Статус `partial`, список `gaps` и `changed_references` требуют проверки. Для PDF сверь порядок колонок, таблицы и схемы с исходными страницами. Номер страницы — адрес PDF; DOCX адресуется путём заголовков и блоком, FB2 — разделом.
5. Просмотри каждое изображение из `images/` и соседнюю подпись. В `*.png.md` запиши фактическое описание и статус `described` либо пометь декоративный рисунок статусом `decorative`. Не угадывай содержание. Оставь статус `requires-description`, если изображение не проверено. После описаний снова проверь полноту по оригиналу: главы, страницы, таблицы, формулы, сноски и изображения. Запусти тот же CLI с исходными параметрами и `--finalize`, чтобы пересчитать статус без повторного извлечения. Не называй результат полным, если остались пробелы.

CLI записывает только в явно указанный каталог результата и сам не меняет общие `knowledge/`, `memory/` и `rules/`. Описания изображений и изменённые указатели после обновления проверь перед использованием. Стандарт из интернета скачивай только по просьбе владельца, фиксируя URL, редакцию и дату.
