# Подтверждённые выводы

Здесь после одобрения точного текста хранятся проверенные выводы из любого источника. Одна запись — один Markdown-файл с понятным именем в `lowercase-kebab-case`. В YAML frontmatter укажите `topics`, `sources`, `updated`; в тексте — вывод, наблюдаемый результат, способ проверки, условия применения и ограничения.

Происхождение не определяет папку: подтверждённая идея из источника переходит сюда из `memory/ideas/`, а проверенный вывод из задачи можно предложить сразу здесь. Если вывод опровергнут или устарел, после одобрения перенесите его в `history/` и пересмотрите связанные правила. Отдельная инструкция агентам, если она нужна, находится в `rules/personal.md`.

Это личная память владельца, а не часть передаваемого фундамента. Для поиска сначала смотрите имена файлов и `topics`, затем открывайте только подходящие записи.
