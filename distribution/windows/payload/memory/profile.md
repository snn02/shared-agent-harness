# Личный профиль владельца

Сюда добавляются подтверждённые владельцем устойчивые сведения о себе, полезные в разных задачах: роль, области интересов, рабочие предпочтения и способ взаимодействия с агентами. Временные состояния и контекст конкретного проекта остаются вне общего профиля. Перед записью агент показывает точный текст и дожидается одобрения.

Пока подтверждённых записей нет.
