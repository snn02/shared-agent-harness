# Идеи для работы

Здесь после одобрения точного текста хранятся личные идеи из любого источника: опубликованного материала, собственной задачи или разговора. Идея может помогать агенту предлагать варианты сразу; она не является обязательным правилом. Проверка на практике нужна только для повышения идеи до подтверждённого вывода или правила.

Одна идея — один файл с понятным именем в `lowercase-kebab-case`. Укажите в YAML frontmatter `topics`, `sources`, `updated`, затем в тексте сформулируйте идею, её возможную пользу и ограничения. План проверки добавляйте лишь если владелец решил проверять идею. Если результат опровергнут или идея устарела, после одобрения перенесите запись в `history/` с причиной и датой.

Для поиска сначала смотрите имена файлов и `topics`, затем открывайте только подходящие идеи. Не считайте этот README списком существующих записей.
