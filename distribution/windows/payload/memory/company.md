# Профиль компании

Сюда добавляются только подтверждённые владельцем сведения о компании, полезные в разных задачах: деятельность, продукты и услуги, устойчивая терминология и типовые процессы. Отмечайте источник подтверждения и дату обновления; изменчивые факты перепроверяйте перед применением.

Не включайте секреты, клиентские данные, сведения конкретного проекта и догадки агента. Этот файл относится к личной памяти владельца и не входит в переносимый фундамент. Перед записью агент показывает точный текст и дожидается одобрения владельца.

Пока подтверждённых записей нет.
