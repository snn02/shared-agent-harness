# Переносимые знания из источников

Сюда помещайте самодостаточные нейтральные выжимки из названных источников. Для каждой выжимки укажите автора или организацию, название, редакцию и ссылки на главы или страницы. Отделяйте положения источника от интерпретации. Если извлечение неполное, укажите пробелы.

Отдельная запись использует короткий YAML frontmatter с `topics`, `sources` и `updated`; подробные ссылки и ограничения остаются в тексте. Личные акценты и идеи находятся в `memory/ideas/`, подтверждённый опыт — в `memory/records/`. В выжимке нет личных сведений, клиентских материалов, секретов или ссылок на файлы за пределами этой папки.

Для передачи коллегам копируйте только эту папку после просмотра её содержания. Список выжимок ведите в `index.md`.
