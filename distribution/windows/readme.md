# Общий agent harness для Windows

Этот пакет создаёт общий каталог `%USERPROFILE%\.agents` с правилами, навыками и пустыми шаблонами знаний. Вы выбираете, к каким из уже установленных Codex, Claude Code и OpenCode его подключить. Начните с короткой [инструкции по установке](installation-guide.md).

## Что входит в пакет

| Файл или папка | Назначение |
| --- | --- |
| `install.cmd` | Запуск установщика двойным кликом. |
| `installation-guide.md` | Простые шаги установки и проверки. |
| `readme.md` | Это описание работы с общими знаниями. |
| `payload/` | Правила, навыки и пустые шаблоны, которые установщик размещает в общем каталоге. |
| `install.ps1`, `manifest.json`, `version.txt` | Служебные файлы установщика. |

После установки отдельный README внутри `.agents` не создаётся. Этот файл остаётся рядом с установщиком: его можно открыть позже.

## Какие навыки уже есть

| Навык | Когда использовать | Что получится |
| --- | --- | --- |
| `memory-maintenance` | Нужно выборочно найти подходящие записи памяти для анализа либо предложить обновление профиля, идеи или проверенного вывода. | При чтении — релевантный контекст для ответа; при изменении — предложение точной правки с ожиданием вашего одобрения. |
| `document-ingest` | Нужно разобрать переданный DOCX, PDF или FB2 в выбранной вами папке, в том числе внутри проекта. | Полный извлечённый текст, индекс разделов и сведения об изображениях. Навык сам не делает выжимку и не добавляет источник в личную библиотеку. |
| `source-to-knowledge` | Нужно выделить переносимые факты или полезные идеи из любого разрешённого материала, уже обработанного или переданного в задаче. | По запросу предлагает нейтральную выжимку в `knowledge/`, личные идеи либо оба результата. При необходимости вызывает общий `document-ingest` в выбранную папку; каждый текст для общей памяти требует вашего одобрения. |

Навыки доступны выбранным приложениям через общий каталог. Для их вызова достаточно обычной просьбы агенту; примеры приведены ниже.
Codex и OpenCode получают короткий `AGENTS.md` в своём каталоге настроек с указанием читать общие правила из `%USERPROFILE%\.agents\AGENTS.md` в новом сеансе. Claude Code получает ссылку на тот же файл в `CLAUDE.md`. Установщик не заменяет занятый пользовательский `AGENTS.md`; такой случай он показывает как конфликт.

## Как устроены знания

| Где | Что хранится |
| --- | --- |
| `knowledge/` | Нейтральные выжимки из источников. После просмотра содержимого эту папку можно передать коллегам отдельно. |
| `memory/profile.md` | Подтверждённые сведения о вашей роли, интересах и предпочтениях. |
| `memory/company.md` | Подтверждённый контекст компании без клиентских данных. |
| `memory/decisions.md` | Принятые межпроектные решения. |
| `memory/ideas/` | Полезные идеи из любого источника. Их можно учитывать при анализе, но они не обязывают агента действовать. |
| `memory/records/` | Выводы, подтверждённые проверенным результатом, с условиями применения. |
| `rules/personal.md` | Ваши отдельно одобренные правила действий агентов. Установщик создаёт пустой шаблон с пояснениями и сохраняет ваши правки при повторной установке. |
| `history/` | Прежние версии, устаревшие и опровергнутые записи. Создаётся по мере работы. |

Одна запись может относиться сразу к нескольким темам, например продажам и управлению проектами. Агент отмечает темы и источник внутри файла, а для задачи выбирает только относящиеся к ней записи. Общая память и отдельная личная библиотека не предназначены для клиентских материалов: с ними работают внутри разрешённого клиентского проекта.
Перед содержательным анализом или рекомендацией агент проверяет индекс фундаментальных знаний и названия с `topics` личных идей и проверенных выводов. Он читает только подходящие записи, указывает их в ответе и отделяет их от общих знаний модели. Простая операция без предметного анализа такого поиска не требует.

Чтобы проверить подбор, откройте новый сеанс выбранного приложения и попросите предложить подходы по теме, для которой вы уже сохранили идею или выжимку, не упоминая память в вопросе. Агент должен сам найти относящиеся записи, назвать их и отличить идею от проверенного вывода. Если по теме записей нет, он должен сказать об этом и ответить на основе других доступных сведений.
Личная библиотека оригиналов и полного разбора — отдельный проект `source-library`; она не создаётся установщиком harness и не входит в его ZIP. Общий навык `source-to-knowledge` можно применять и к источнику вне библиотеки.

## Как начать наполнять знания

Пишите агенту обычным языком в Codex, Claude Code или OpenCode. Специальные команды и самостоятельное редактирование файлов не нужны. Перед записью агент должен показать вам точный текст и место сохранения; подтвердите запись только после просмотра.

**Профиль о себе**

> Помоги составить мой профиль для общего agent harness. Спроси только то, чего не хватает для полезной записи: о моей роли, устойчивых интересах и предпочтениях в работе с агентами. Покажи, что запишешь, и дождись моего одобрения.

**Профиль компании**

> Помоги составить профиль компании для общего agent harness. Уточни деятельность, продукты, терминологию и типовые процессы. Не включай клиентов и сведения отдельного проекта. Покажи текст до сохранения.

**Источник: книга, стандарт или статья**

> Помоги разобрать этот источник и добавить его в мои фундаментальные знания. Покажи пробелы разбора, нейтральную выжимку и отдельно идеи, полезные для моей работы. Ничего не сохраняй до моего одобрения.

Для локальных DOCX, PDF и FB2 агент использует навык `document-ingest` с явно выбранным каталогом результата. В отдельном проекте `source-library` разбор и индекс выполняются по его инструкции; общий `source-to-knowledge` помогает затем сделать выжимку или идею из этого или любого другого разрешённого источника. При первом разборе может понадобиться Python 3.12 и зависимости: агент сообщит, чего не хватает, и предложит настройку. Для сканированных PDF нужен OCR; в этой версии он ещё не проверен, поэтому пропуски распознавания должны быть явно указаны.

**Новая идея или проверенный вывод**

> Предложи сохранить эту мысль как идею для будущих задач. Укажи источник и области применения, покажи точный текст до записи.

> Этот подход дал проверенный результат. Помоги оформить вывод: что произошло, как мы это проверили, когда он применим и какие есть ограничения. Покажи запись до сохранения.

Полезная идея не требует предварительного практического подтверждения. После проверки агент может предложить перенести её в подтверждённые записи. Если вы хотите, чтобы агент **обязательно действовал** по выводу, отдельно согласуйте точный текст правила. Устаревшую или опровергнутую запись агент предложит перенести в историю с причиной.

Структуру отдельных записей агент оформляет сам: темы, происхождение и дату обновления он указывает в коротких метаданных файла. Автоматическая память Claude Code остаётся отдельной; перенос из неё в общую память требует вашего одобрения.

**Личные правила и расположение библиотеки**

В `rules/personal.md` запишите правило только после того, как согласовали его точный текст. Шаблон подсказывает, как указать условие применения, действие агента и границы. Там же можно указать путь к вашей личной библиотеке на этом компьютере и требование сначала прочитать её `AGENTS.md`. Пакет не содержит чужих личных путей и не переносит источники в библиотеку автоматически. Установщик создаёт файл при отсутствии и больше не меняет его содержимое.

## Что пакет не делает

Установщик не ставит сами приложения, Python или OCR и не настраивает WSL, хранилище секретов либо внешнюю резервную копию. Не помещайте секреты и клиентские данные в общий каталог. Сделайте собственную периодическую копию изменённых знаний вне этого компьютера: этот пакет не создаёт её автоматически.

Обновления приходят новым ZIP и устанавливаются вручную. Установщик показывает изменения перед записью и сохраняет ваши локальные правки для сравнения; он не удаляет старые файлы автоматически.
