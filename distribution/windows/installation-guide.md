# Установка общего agent harness в Windows

Этот пакет подключает общие правила и навыки к уже установленным Codex, Claude Code и OpenCode. Установщик сам найдёт доступные приложения и предложит выбрать нужные. Что входит в пакет и как затем наполнять знания, описано в [readme.md](readme.md).

## Установка

1. Получите файл `agent-harness-windows-v0.4.3.zip` от коллеги и распакуйте его в отдельную папку.
2. Откройте распакованную папку: рядом с `install.cmd` должен лежать `manifest.json`. Дважды щёлкните `install.cmd`.
3. В открывшемся окне отметьте галочками приложения, к которым хотите подключить harness, и нажмите «Продолжить». Если окно недоступно, выберите приложения по номерам в консоли.
4. Посмотрите, какие файлы и настройки установщик собирается изменить. Если он обнаружил ваши файлы, прочитайте сообщение о конфликте. Когда список вас устраивает, введите `Yes` для подтверждения; регистр букв не важен.
5. Дождитесь итогового отчёта. Если видите `conflict` или `error`, сохраните текст сообщения: по нему можно понять, что нужно исправить.

Установщик не скачивает Codex, Claude Code или OpenCode и не обновляет их. Существующие пользовательские файлы он не перезаписывает молча.
Если вы дополнили файл знаниями, а в новом пакете этот файл не менялся, установщик сохранит вашу версию без ошибки. Если изменились обе версии, он покажет конфликт для ручного сравнения.

## Проверка

Откройте новый сеанс выбранного приложения и спросите: «Какие общие правила и навыки доступны тебе в моём agent harness?» Агент должен найти общий каталог `%USERPROFILE%\.agents`. Если не находит, передайте ему итоговое сообщение установщика и попросите помочь разобраться.

## Если установка прошла частично

Чаще всего нужно решить конфликт с существующим файлом. Установщик укажет конкретный путь и причину. Ваши прежние файлы сохраняются; после исправления причины можно снова запустить `install.cmd`. Для подключения Codex и OpenCode права администратора не требуются.

Когда позже появится новая версия пакета, распакуйте новый ZIP в другую папку и запустите его установщик тем же способом. Он покажет изменения до записи и сохранит ваши собственные правки для ручного сравнения.
